# 串口打印乱码怎么查

乱码这个现象很有欺骗性：看着像程序错，大半出在时钟和参数上。

## 1. 波特率误差超了

串口能容忍的误差大约 2% 以内。
用内部 RC 振荡器做时钟源时，温漂一上来误差就超标，收出来就是乱码。

**验证方式**：换成外部晶振再看。不乱码了，就是时钟精度问题。

## 2. 时钟树没配对

外设时钟使能了，但分频系数还是默认值，实际波特率和设定值对不上。
从别人工程拷代码时特别常见。

**验证方式**：算一遍 PCLK → USARTDIV → 实际波特率，和设定值对比。

## 3. 中断里做 printf

串口发送是阻塞的，放中断里会拖长中断时间，高波特率下直接丢字节。
要么改 DMA，要么把打印挪到主循环。

## 4. 还有两个低级但高频的

- TX / RX 接反
- 两块板子没共地

## 排查顺序建议

先看波形再看代码。乱码是物理层的事，代码只是其中一个可能。
