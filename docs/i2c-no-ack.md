# I2C 读不到从机

很多人第一反应是驱动写错了，实际硬件问题占大多数。

## 1. 上拉电阻

SDA 和 SCL 都必须上拉，通常 4.7k。
速率高或总线电容大时降到 2.2k。
没有上拉，线上永远是低电平，扫不到任何地址。

## 2. 地址

很多传感器的地址由 ADDR 引脚电平决定，同一型号有两种地址，手册第一页就写了。
用扫描程序把所有地址过一遍，比猜快得多。

## 3. 共地

两块板子单独供电但没共地，电平参考不一样。
波形能测出来，但通信一定失败。

## 4. 总线死锁

从机在传输中途被复位，会一直拉住 SDA 不放。
这时候主机发什么它都不应答。

**解法**：主机手动发 9 个时钟脉冲把从机顶出来，再发一个停止条件。

## 5. 最后才怀疑代码

先看时序，特别是：
- 标准模式（100k）和快速模式（400k）混用
- 时钟延展（clock stretching）没处理
- 重复起始条件用法不对

顺序反了，会花一整天改一个本来没错的驱动。
