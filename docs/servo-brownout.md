# 四颗舵机一起动，单片机就复位

做四足机器人时遇到的。单颗舵机动，一切正常；四颗同时动，单片机随机复位、串口乱码、有时直接掉线。

## 排查过程

第一反应是代码问题：加互斥、改任务优先级、PWM 分时输出 —— 都没用。

后来串了个电流表才看明白：
SG90 空载电流很小，但**堵转电流能到 700mA 左右**。
四颗一起动作，瞬时接近 3A。USB 口给不出这个电流，电压瞬间跌下去，单片机欠压复位。

这个现象特别迷惑人：**它不像断电，它像程序有 bug**。

## 三个解法（按成本排）

1. 舵机单独供电，和单片机共地但不共电源
2. 电源端并一个大电容吸收瞬时电流
3. 上电时序：先给单片机，延时一会儿再使能舵机

## 通用结论

任何"多路大电流负载 + 单片机"的组合，先量峰值电流和电压跌落，再谈代码。
